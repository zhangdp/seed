# seed

> 基于 **Spring Boot 4** 的 RBAC 权限管理系统种子项目（脚手架）

一个开箱即用的后台管理系统底座，内置用户 / 角色 / 权限 / 部门 / 字典 / 参数管理，以及认证授权、验证码、短信、文件存储、操作日志等常用基础能力，适合作为新项目的起点。

## 快速开始

### 1. 准备数据库

创建数据库与账号（示例）：

```sql
CREATE DATABASE seed_db;
CREATE USER seed WITH PASSWORD '123456';
GRANT ALL PRIVILEGES ON DATABASE seed_db TO seed;
```

依次执行建表与初始化脚本（顺序不能颠倒）：

```bash
# 建表（含 DROP TABLE，仅用于开发/测试环境初始化）
psql -h 127.0.0.1 -U seed -d seed_db -f sql/seed-schema.sql
# 初始化数据
psql -h 127.0.0.1 -U seed -d seed_db -f sql/seed-data.sql
```

### 2. 修改配置

按需修改 `src/main/resources/application.yml` 中的数据源、Redis 连接信息（默认 `127.0.0.1` / 密码 `123456`）：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://127.0.0.1:5432/seed_db?currentSchema=public
    username: seed
    password: 123456
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password: 123456
```

### 3. 启动

```bash
mvn spring-boot:run
```

启动后：

- 服务地址：<http://localhost:8080>
- 接口文档（Swagger UI）：<http://localhost:8080/swagger-ui.html>
- 健康检查：<http://localhost:8080/actuator/health>

## 核心能力

### RBAC 权限模型

- 实体：`User`、`Role`、`Permission`（菜单/按钮）、`Dept`、`Dict` / `DictData`、`Config`。
- 关联：`sys_user_role`、`sys_role_permission`。
- 权限标识采用 `模块:资源:操作` 格式（如 `sys:user:add`），通过 Spring Security 的 `@PreAuthorize("hasAuthority('sys:user:add')")` 在接口上做方法级鉴权。
- 提供菜单树、部门树、权限树接口，前端可据此渲染动态菜单与按钮。

### 认证与令牌

- 支持 **密码登录** 与 **短信验证码登录** 两种方式。
- 采用 **JWT 访问令牌 + 刷新令牌** 双令牌机制：
  - 访问令牌默认有效期 `30m`，刷新令牌默认 `24h`。
  - 令牌持久化在 Redis，注销 / 顶号通过 **jti 黑名单** 实现，并借助 Redis 发布订阅完成跨节点版本同步。
  - 无状态（`STATELESS`），不依赖 Session。
- 通过 `@IgnoreAuth` 注解或 `app.security.permit-urls` 配置放行无需认证的接口。
- 控制器可直接注入 `LoginUser` 获取当前登录用户（由参数解析器自动注入）。

### 验证码

- **图形验证码**：基于 Hutool 生成，返回 `key` 与图片 Base64，宽高可配置且有上下限夹取，防止被构造超大图片。
- **短信验证码**：支持发送间隔限制、每日上限、场景白名单。
- 校验通过 `@VerifyCaptcha` 切面完成（SpEL 指定 key/code 参数），校验并消费验证码后才会进入业务逻辑。

### 短信模块

- **两段式发送**：业务侧「新增落库排队」→ 内置定时任务「调度派发」，发送入口与调度解耦，后续可平滑替换为消息队列。
- 支持按「优先级降序、主键升序」批量领取，失败自动重试（可配置最大重试次数），发送中状态超时可被其他节点重新领取。
- `SmsSender` 可扩展，默认提供 `LogSmsSender`（日志输出），可按需接入阿里云 / 腾讯云等服务商。

### 文件存储

- 统一 `StorageAdapter` 抽象，内置 **本地磁盘** 与 **S3 对象存储** 两种实现，`app.file-storage.s3.enabled` 切换。
- 支持上传、下载（含 HTTP 缓存、inline 预览）、过期时间、MIME 类型映射。

### 日志体系

- **登录日志**：记录登录类型、结果、IP、User-Agent 等（通过登录事件异步落库）。
- **操作日志**：在接口上标注 `@RecordLog`，由切面记录操作类型、入参、返回值、耗时、异常堆栈等，配合 `@EnableRecordOperationLog` 开启。
- **短信日志**：记录每条短信的发送状态、重试次数与服务商回执。

### 通用基础设施

- **统一响应**：`WrapperResponseBodyAdvice` 自动将返回值包装为 `R<T>（code/message/data）`，`0` 表示成功；`@NoWrapperResponse` 可跳过包装。
- **全局异常处理**：`GlobalExceptionHandleAdvice` 将业务异常、校验异常、系统异常统一转换为 `R` 结构。
- **错误码规范**：`ErrorCode` 由 5 位数字组成，首位表示错误来源（1 用户 / 2 业务 / 3 系统 / 4 中间件 / 5 第三方）。
- **数据脱敏**：字段标注 `@Sensitive(type)`，接口标注 `@Desensitization`，即可在返回时按类型自动脱敏（手机号、身份证、邮箱、银行卡等）。
- **JSON 处理**：请求字符串自动 trim（`@JsonTrim` / `@NoJsonTrim`），Long 转字符串防精度丢失（`SafeLongSerializer`）。
- **事件机制**：`@PublishEvent` 发布领域事件，`event/handler` 中以 `@EventListener` 异步处理（如登录日志、操作日志落库）。
- **MyBatis-Flex**：逻辑删除（`deleted` 字段）、雪花 ID 主键、创建/更新时间自动填充。

## 接口一览

> 除标注「公开」外，其余接口均需登录，并受对应权限标识约束。完整参数与响应见 Swagger UI。

### 认证 `/auth`

| 方法     | 路径                     | 说明           | 权限 |
| ------ | ---------------------- | ------------ | -- |
| POST   | `/auth/login/password` | 密码登录（需图形验证码） | 公开 |
| POST   | `/auth/login/sms`      | 短信验证码登录      | 公开 |
| DELETE | `/auth/logout`         | 注销（作废令牌）     | 公开 |
| POST   | `/auth/token/check`    | 检测令牌有效性      | 登录 |
| POST   | `/auth/token/refresh`  | 刷新令牌续签       | 公开 |
| GET    | `/auth/user/menus`     | 当前用户菜单树      | 登录 |
| GET    | `/auth/user/info`      | 当前用户信息       | 登录 |

### 验证码 `/captcha`

| 方法   | 路径               | 说明      | 权限 |
| ---- | ---------------- | ------- | -- |
| GET  | `/captcha/image` | 获取图形验证码 | 公开 |
| POST | `/captcha/sms`   | 发送短信验证码 | 公开 |

### 系统管理 `/sys/**`（示例）

| 模块   | 路径前缀                | 主要能力            |
| ---- | ------------------- | --------------- |
| 用户   | `/sys/user`         | 增删改、分页查询（返回脱敏）  |
| 角色   | `/sys/role`         | 增删改、分页、列表、分配权限  |
| 权限   | `/sys/permission`   | 增删改、权限树         |
| 部门   | `/sys/dept`         | 增删改、部门树         |
| 字典   | `/sys/dict`         | 字典及字典项增删改、分页、列表 |
| 参数   | `/sys/config`       | 增删改、分页、列表       |
| 登录日志 | `/sys/login/log`     | 分页查询（游标分页）      |
| 操作日志 | `/sys/operation/log` | 分页查询（游标分页）      |
| 短信日志 | `/sys/sms/log`       | 分页查询（手机号脱敏）     |
| 定时任务 | `/sys/job`、`/sys/job/log` | 增删改、分页、启停、立即执行、执行日志查询与清空 |

### 文件 `/file`

| 方法   | 路径                           | 说明   | 权限 |
| ---- | ---------------------------- | ---- | -- |
| POST | `/file/upload`               | 上传文件 | 登录 |
| GET  | `/file/download/{fileId}/**` | 下载文件 | 登录 |

## 配置说明

主要配置位于 `application.yml`，均以 `app.*` 为前缀（生产环境覆盖见 `application-prod.yml`）。

### `app.security` 认证

```yaml
app:
  security:
    access-token-ttl: 30m      # 访问令牌有效期
    refresh-token-ttl: 24h     # 刷新令牌有效期
    enable-refresh-token: true # 是否启用刷新令牌
    permit-urls:               # 免认证路径
      - /favicon.ico
      - /swagger-ui/**
      - /v3/api-docs/**
      - /actuator/**
      - /error
    jwt:
      secret: <至少 32 字节的签名密钥>   # 多节点必须显式配置，否则各节点验签失败
      issuer: seed
    actuator:                  # Actuator 独立 Basic 认证
      enabled: true
      username: actuator
      password: Seed@2026
      roles: ACTUATOR
      permit-urls: health,info
```

### `app.captcha` 验证码

```yaml
app:
  captcha:
    image-expire: 5m           # 图形验证码有效期

    sms-code-length: 6
    sms-max-per-mobile-per-day: 20  # 单手机号每日上限
    sms-scenes:                # 场景白名单
      - login
      - register
      - reset_password
      - bind_mobile
      - change_mobile
```

## 开发约定

- **包结构**：`common`（通用能力）、`module`（可插拔功能模块）、`controller` / `service` / `manager` / `mapper` / `entity` 分层。
- **新增接口**：在控制器方法上按需组合 `@RecordLog`（操作日志）、`@PreAuthorize`（权限）、`@Desensitization`（脱敏）、`@VerifyCaptcha`（验证码）、`@PublishEvent`（事件）。
- **无需认证的接口**：在方法或类上添加 `@IgnoreAuth`。
- **数据脱敏**：在返回对象的敏感字段上标注 `@Sensitive(SensitiveType.XXX)`。
- **错误码**：在 `ErrorCode` 中按来源分类新增，保持「1 用户 / 2 业务 / 3 系统 / 4 中间件 / 5 第三方」的编码规范。
